# Changelog

All notable changes to CookiePrime iOS SDK will be documented in this file.

## [1.0.0] - 2024-01-15

### Added
- Initial release
- Deferred SDK initialization
- 8-method SDK detection (dyld, classes, selectors, bundles, etc.)
- 40+ SDK registry
- Consent management with UserDefaults + Keychain storage
- Adapters for Firebase, Facebook, AdMob, AppsFlyer
- Offline support with pending operations queue
- SwiftUI and UIKit consent UI
- Telemetry and performance monitoring
- Migration assistant for legacy SDKs
- PrivacyInfo.xcprivacy manifest
- SPM and CocoaPods support
- XCFramework distribution

### Requirements
- iOS 14.0+
- Swift 5.9+
- Xcode 15.0+
